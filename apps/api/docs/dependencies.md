### @asteasolutions/zod-to-openapi

[@asteasolutions/zod-to-openapi](https://www.npmjs.com/package/@asteasolutions/zod-to-openapi) is a library that converts Zod schemas to OpenAPI documentation, allowing for easy integration of Zod validation with OpenAPI standards.

### @duffel/api

[@duffel/api](https://www.npmjs.com/package/@duffel/api) is the official Node.js library for the Duffel API, used for accessing flight booking and airline data.

### @node-rs/argon2

[@node-rs/argon2](https://www.npmjs.com/package/@node-rs/argon2) is a high-performance Rust implementation of the Argon2 password hashing algorithm for Node.js.

### @prisma/client

[@prisma/client](https://www.npmjs.com/package/@prisma/client) is an auto-generated query builder that enables type-safe database access.

### aircodes

[aircodes](https://www.npmjs.com/package/aircodes) provides utilities for working with airline and airport codes.

### argon2

[argon2](https://www.npmjs.com/package/argon2) is a password hashing library implementing the Argon2 algorithm.

### axios

[axios](https://www.npmjs.com/package/axios) is a promise-based HTTP client for browser and Node.js.

### cls-hooked

[cls-hooked](https://www.npmjs.com/package/cls-hooked) implements continuation-local storage for Node.js.

### cookie-parser

[cookie-parser](https://www.npmjs.com/package/cookie-parser) is middleware for parsing Cookie header and populating req.cookies.

### cors

[cors](https://www.npmjs.com/package/cors) is a node.js package for providing a Connect/Express middleware that can be used to enable Cross-Origin Resource Sharing (CORS) with various options.

### cron

[cron](https://www.npmjs.com/package/cron) is a tool for scheduling tasks in Node.js using cron syntax.

### cronstrue

[cronstrue](https://www.npmjs.com/package/cronstrue) converts cron expressions into human-readable descriptions.

### dotenv

[dotenv](https://www.npmjs.com/package/dotenv) is a zero-dependency module that loads environment variables from a `.env` file into `process.env`, helping to manage environment-specific settings.

### envalid

[envalid](https://www.npmjs.com/package/envalid) is a small library for validating and accessing environment variables in Node.js, ensuring they meet specified criteria.

### express

[express](https://www.npmjs.com/package/express) is a fast, unopinionated, minimalist web framework for Node.js, used for building web and mobile applications.

### express-rate-limit

[express-rate-limit](https://www.npmjs.com/package/express-rate-limit) is a basic IP rate-limiting middleware for Express, used to limit repeated requests to public APIs and endpoints.

### helmet

[helmet](https://www.npmjs.com/package/helmet) helps secure Express apps by setting various HTTP headers, providing several middleware functions to enhance security.

### http-status-codes

[http-status-codes](https://www.npmjs.com/package/http-status-codes) is a library for easily
referencing HTTP status codes by their standard names and numeric values.

### jsonwebtoken

[jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken) is an implementation of JSON Web Tokens for authentication, used for secure token-based authentication.

### luxon

[luxon](https://www.npmjs.com/package/luxon) is a library for working with dates and times in JavaScript, providing a modern and friendly API for date and time manipulation.

### node-cache

[node-cache](https://www.npmjs.com/package/node-cache) is a simple and fast Node.js internal caching module, used for caching frequently accessed data to improve performance.

### nodemailer

[nodemailer](https://www.npmjs.com/package/nodemailer) is a module for sending emails from Node.js applications, supporting various email services.

### nodemailer-express-handlebars

[nodemailer-express-handlebars](https://www.npmjs.com/package/nodemailer-express-handlebars) is a plugin for Nodemailer that uses Handlebars to generate email templates.

### pino-http

[pino-http](https://www.npmjs.com/package/pino-http) is an HTTP logger for Node.js using the Pino logging library, providing a high-performance, low-overhead logger for HTTP servers.

### prisma-error-enum

[prisma-error-enum](https://www.npmjs.com/package/prisma-error-enum) provides error code enums for Prisma database errors, helping to handle and manage database errors more effectively.

### redis

[redis](https://www.npmjs.com/package/redis) is a high-performance Redis client for Node.js.

### stripe

[stripe](https://www.npmjs.com/package/stripe) is the official Stripe API client library for Node.js, used for integrating Stripe payment processing into applications.

### swagger-ui-express

[swagger-ui-express](https://www.npmjs.com/package/swagger-ui-express) is middleware for serving auto-generated Swagger UI for your API documentation, providing a user-friendly interface for API documentation and testing.

### zod

[zod](https://www.npmjs.com/package/zod) is a TypeScript-first schema declaration and validation library, offering a simple and powerful way to validate data structures.
