# Plan Home

Hero card with week progress and today’s session CTA.

## API dependencies

| Step | Method | Path |
|------|--------|------|
| Active plan | GET | `/training-plans/active` |
| Apply progression | POST | `/training-plans/:id/apply-weekly-progression` |
| Changes | GET | `/training-plans/:id/changes` |

## Mobile screens

- `PlanHome`
- `PlanChangeBanner` (inline)
