# Create Component Design (Flex)

Create `/design/system/components/{componentName}.component.design.pen`.

## Frame Naming

`"{ComponentName} Component ({Variant}): {State}"`

## States

Default, selected, completed, disabled (as applicable).

## Code Target

Maps to `apps/mobile/src/shared/components/{ComponentName}/`.

## Token Annotations

Reference `apps/mobile/src/shared/styles/StyleConstants.ts` paths.
