# UI Patterns

Reusable treatments applied across flows.

## Selection Card

White surface, `radii.lg`, 1px `colors.border`. Selected: 2px `colors.textPrimary` border + checkmark.

## Week Strip

7-day horizontal row; today = filled `colors.textPrimary` circle on date number.

## Coach Note

Horizontal row: 32px avatar, `typography.bodyLarge` message, "see more" link in `colors.textSecondary`.

## Progress Header

"Step X of Y" caption + 4px tall progress bar; fill `colors.accentEnergy`.

## Modality Bar

4px left edge on workout cards — color by type (strength, cardio, mobility, conditioning).
