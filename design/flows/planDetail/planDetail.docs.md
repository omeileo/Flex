# Plan Detail Flow

Program drill-down from **Plan tab** through phase rules, exact weekly exercises, session warm-up/main work, and exercise detail.

## Steps

1. **Program overview** — Plan blurb (goal, injuries, equipment, running), phase cards
2. **Phase detail** — Goal, RPE, progression, rest policy, split + running block
3. **Week schedule** — Exact exercise preview per day (Mon–Sat)
4. **Workout day detail** — Warm-up + main work, coach note, Start workout
5. **Exercise detail** — Prescription, history, instructions, injury note
