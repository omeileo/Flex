# Frame Naming & Organization

## Format

```
<Frame Name>: <Description> [- Final]
```

## Flow Files (`/design/flows/`)

- Main path: left → right, chronological
- Error/branch states: below related step (150px)
- Spacing between steps: 200px horizontal

Example:

```
Onboarding Flow Step 1: Goal selection
Onboarding Flow Step 2: Injury history
Onboarding Flow Step 3: Current injury state
```

## Component Files

States left → right: default → selected → completed → disabled

## Token Files

Grouped by category, light → dark or small → large values.
