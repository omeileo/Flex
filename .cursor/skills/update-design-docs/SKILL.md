# Update Design Docs (Flex)

Keep markdown in `/design/` aligned with current `.pen` files.

## Files to Update

- Flow-specific: `design/flows/{name}/{name}.docs.md`
- Index: `design/flows/flows.docs.md`
- Tokens: `design/docs/themeTokens.docs.md`
- Components: `design/system/components/components.docs.md`

## Process

1. Scan folder for `.pen` files
2. List frames and their purpose
3. Update docs with current step breakdown and integration notes
